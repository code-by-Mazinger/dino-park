# Дино-парк

Игра для маленького знатока динозавров, который только учится читать. Чтение — ключ к динозаврам: раскопал окаменелость → собрал имя из слогов → динозавр ожил и поселился в парке.

Играть: https://code-by-mazinger.github.io/dino-park/ (на iPhone — Поделиться → На экран «Домой»).

## Как играть
- **Раскопки:** счищай песок пальцем — под ним окаменелость. На кнопке раскопок — силуэт «Кто прячется в земле?».
- **Имя по слогам:** голос говорит слог («СТЕ»), найди карточку. Ошибся — голос повторит, после двух промахов нужная карточка подсветится. 🔊 — послушать ещё раз.
- **Парк:** найденные динозавры гуляют, птеранодон летает. Нажми на динозавра — карточка: имя по слогам (каждый слог озвучивается), чем питался, период, три факта голосом.
- 15 видов по нарастающей: сначала имена из 3 слогов (СТЕ-ГО-ЗАВР), в конце из 5 (ВЕ-ЛО-ЦИ-РАП-ТОР). Лишних карточек: 1 → 2 → 3, похожие по первой букве.
- **🍖 Голодный динозавр:** голос говорит слог, сверху падают слоги-листочки — накорми динозавра нужным (10 — и он сыт). Слоги — из имён найденных динозавров; после двух промахов слог подсказывается текстом.
- **🧑‍🔬 Профессор-путаник:** 8 утверждений про найденных динозавров, половина — его ошибки (по одной на вид, с поправкой). «Верно» / «Ошибка!»; ответил правильно, не нажимая 🔊, — ⭐ «прочитал сам».
- **Самбо:** после тренировки взрослый нажимает «🥋 Был на самбо!» и отвечает на вопрос из таблицы умножения (6…9 × 6…9) — чтобы ребёнок не отмечал сам; раз в день. Каждая тренировка — трещина на яйце, три — вылупляется малыш (тираннозавр, трицератопс, стегозавр, диплодок, анкилозавр по кругу). Дино-пояс растёт по числу тренировок: белый → жёлтый (3) → оранжевый (6) → зелёный (10) → синий (15) → коричневый (21) → чёрный (30) — игровой, не система самбо.
- Факты — только надёжные; где учёные не уверены — «учёные думают». Птеранодон честно подписан «не динозавр».

## Файлы
| Что | Где |
|---|---|

| Карточки слогов с лишними | `logic.js` |
| Рисунки динозавров (нейросеть, вырезаны из одного листа на зелёном фоне; окаменелость и силуэт — CSS-фильтром) | `dinos/*.webp` |

| Парк, раскопки, голос (синтез речи телефона), звуки | `game.js`, `index.html` |
| Офлайн (новая версия — поменять `VER`) | `sw.js` |
